# Directorio de Recursos de Econometría y Ciencia de Datos

Colección de libros interactivos, manuales y repositorios de código abierto para econometría aplicada, inferencia causal y programación.

> **Aviso:** No soy propietario ni autor de ninguno de estos recursos, ni los he revisado todos de forma exhaustiva. Este espacio funciona simplemente como un archivo personal para almacenar enlaces que me parecen interesantes y que pueden ayudarme a aprender en el futuro o cuando los necesite.

## 1. Ciencia de Datos y Programación General

* **[R para Ciencia de Datos (R4DS - Español)](https://davidrsch.github.io/r4ds-es/)** — *Materia: Programación y Gestión de Datos*
  Fundamentos del ecosistema `tidyverse` para importar, limpiar y estructurar bases de datos antes del modelado econométrico. **(Aplicaciones en R)**.

* **[Coding for Economists](https://aeturrell.github.io/coding-for-economists/)** — *Materia: Econometría Computacional*
  Libro práctico para economistas, desde OLS básico hasta efectos fijos. **Todo el material y los ejemplos se desarrollan en Python**.

## 2. Microeconometría y Modelamiento Aplicado

* **[Diplomado en Econometría UNAM (Módulo 4)](https://github.com/DiegoSReco/UNAM_Econometrics_Diploma_Microeconometrics)** — *Materia: Microeconometría Avanzada*
  Material de enseñanza en GitHub sobre modelos de variables binarias y datos de panel, **con aplicaciones y código en R**.

* **[Introduction to Econometrics with R](https://www.econometrics-with-r.org/)** — *Materia: Econometría Aplicada*
  Compañero interactivo del manual de Stock y Watson, ideal para aplicar la teoría empírica tradicional directamente en código. **(Aplicaciones en R)**.

* **[Principles of Econometrics with R](https://bookdown.org/ccolonescu/RPoE4/)** — *Materia: Modelamiento Empírico*
  Guía paso a paso para estimar regresiones simples, múltiples, series de tiempo y estructuras de datos de panel. **(Aplicaciones en R)**.

* **[R: Uma Introdução para Economistas](https://danmrc.github.io/R-para-Economistas/)** — *Materia: Programación y Macroeconometría*
  Manual muy conciso en portugués orientado a resolver problemas econométricos y aplicar filtros macroeconómicos. **(Aplicaciones en R)**.

## 3. Inferencia Causal y Evaluación de Impacto

* **[Causal Inference: The Mixtape](https://mixtape.scunning.com/)** — *Materia: Evaluación de Impacto*
  El estándar moderno para aprender inferencia causal, incluyendo matching y regresión discontinua. **Código en R, Stata y Python**.

* **[The Effect](https://theeffectbook.net/)** — *Materia: Diseño de Investigación Causal*
  Texto clave que explica la intuición teórica de la econometría antes de modelar, **con código disponible en R, Stata y Python**.

## 4. Flujos de Trabajo y Referencias (Stata)

* **[DIME Analytics Data Handbook (Banco Mundial)](https://worldbank.github.io/dime-data-handbook/)** — *Materia: Flujos de Trabajo en Stata*
  Guía metodológica para limpieza de encuestas, generación de tablas de balance y exportación automatizada de resultados a LaTeX.

* **[Stata Tutorial (Princeton)](https://grodri.github.io/stata/)** — *Materia: Referencia de Sintaxis en Stata*
  Guía rápida y directa para recordar la programación básica, gestión de datos y estimación estadística.

* **[UCLA OARC Stata Data Analysis Examples](https://stats.oarc.ucla.edu/stata/)** — *Materia: Ejemplos Prácticos de Código en Stata*
  Repositorio gigante con problemas metodológicos resueltos y comentados paso a paso.
